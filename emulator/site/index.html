On-screen keys F1 monitor · F4 BASIC · arrows

F1 monitor: $0000–$00C7 is cleared on boot. Tap PgDn once for live zero-page variables from $00D8. Up/Down move 8 bytes; PgUp/PgDn move one screen. Esc exits.

BASIC programs F4 · paste · run

F4 starts Microsoft/OSI BASIC. Press Enter twice to accept the memory-size and terminal-width defaults, or use to do that for you. Starting BASIC clears the current program.

Select a sample or paste a listing here. Include RUN to start it.

Listings that start with NEW restart BASIC first. Known limits of this ROM build (they happen on the real board too): arithmetic and comparison operators fail, and after about 128 typed characters in one BASIC session input gets corrupted. Press F4 to start fresh.

Tap the screen to type. F4 starts BASIC; Esc clears the ROM monitor.

Keyboard

Tap the VGA screen for your phone keyboard. Press F4 for BASIC; the BASIC programs drawer has editable examples and a paced paste sender. The on-screen keys stay available in fullscreen.
